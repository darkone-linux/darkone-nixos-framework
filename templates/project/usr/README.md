# `usr/` — your local overlay

This is **your** layer. The framework lives in the nix store (via the `dnf`
flake input) and never reaches into your repo by relative path — it only
reads what you put here.

## Subdirectories

- **`modules/`** — additional NixOS modules specific to this deployment.
  `default.nix` is an import index regenerated by `just generate`.
- **`home/`** — home-manager overlay applied to every user of every host.
  `home/modules/default.nix` is generated; `home/default.nix` is yours.
- **`home/profiles/<name>/`** — your own user profiles, referenced from
  `etc/config.yaml:users.<login>.profile` (see the README there).
- **`home/nixos/<name>.nix`** — NixOS side of each custom profile above.
- **`users/<login>/`** — per-user customizations. One directory per declared
  user, **required** (it is imported unconditionally).
- **`machines/<hostname>/`** — per-host files: `configuration.nix` (yours),
  `install/` (frozen at install), `hardware/` (probed). See its README.
- **`hosts/disko/<name>.nix`** — your own disk layouts, if the framework
  profiles (`dnf/hosts/disko/`) don't fit. Same name = shadows the framework one.
- **`secrets/`** — SOPS-encrypted secrets and the deploy public key. Created
  by `just configure-admin-host`. **Never** edited by hand or by automation.

## Convention

- `default.nix` files at the top of `usr/modules/` and `usr/home/modules/`
  are **generated** by `just generate`. Header: `# DO NOT EDIT`.
- Hand-written entry points (e.g. `usr/home/default.nix`, which imports
  `./modules`) are yours to maintain.
- Everything under `usr/` must be committed — nix flakes ignore untracked
  files.
